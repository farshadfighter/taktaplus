# چک‌لیست تست روی دستگاه و سرور واقعی

همه‌ی ماژول‌ها با تست خودکار و سرورهای شبیه‌سازی‌شده (FortiGate/FortiWeb جعلی، SSH جعلی، ClickHouse و PostgreSQL واقعی) تست شده‌اند. این فهرست چیزهایی است که **فقط روی دستگاه و سرور واقعی** قابل تأیید است. موارد ⚠️ آن‌هایی‌اند که رفتار دستگاه واقعی ممکن است با شبیه‌ساز فرق کند و احتمال نیاز به اصلاح کد دارند.

برای هر مورد ستون «نتیجه» را با ✅ / ❌ و توضیح کوتاه پر کنید و نسخه‌ی FortiOS/FortiWeb را بنویسید.

## ۰. آماده‌سازی

| | مورد | نیاز |
|---|---|---|
| ☐ | سرور Linux x86_64 با Docker Engine و Compose plugin، ۴ هسته و ۸ گیگ حافظه، ۱۰۰ گیگ دیسک | |
| ☐ | دست‌کم یک FortiGate (ترجیحاً ۷.۲ و ۷.۴) و یک FortiWeb؛ یک FortiGate در HA اگر در دسترس است؛ یک FortiGate با VDOM | |
| ☐ | کاربر REST API (Administrator → REST API Admin) با Trusted Host آدرس سرور، و کاربر SSH | |
| ☐ | کلید انتشار (`lictool keygen -kid rel-…`) و قرار دادن `.pub` در `internal/system/keys/` و `internal/releasekeys/keys/` | |
| ☐ | کلید امضای لایسنس و پکیج برای سرور لایسنس | |

## ۱. نصب و ارتقا (فاز ۸)

| | تست | مراحل | انتظار | نتیجه |
|---|---|---|---|---|
| ☐ ⚠️ | ساخت ایمیج تولید | `scripts/release/build-bundle.sh 1.0.0 <key>` روی ماشینی با اینترنت | ایمیج با Chromium و `postgresql16-client` ساخته می‌شود (در محیط توسعه به‌خاطر دسترسی به مخزن Alpine تست نشد) | |
| ☐ ⚠️ | ایمیج updater | `docker:27-cli` در بسته باشد و `docker compose version` داخلش کار کند | | |
| ☐ | نصب | `sudo ./install.sh <IP>` | بارگذاری، تأیید امضا، `.env` با دسترسی ۶۰۰، پنل روی HTTPS | |
| ☐ | تأیید امضا | یک بایت از `images/images.tar` را تغییر دهید و نصب کنید | نصب با «damaged» متوقف شود | |
| ☐ | ساخت مدیر و ورود با TOTP | `create-admin` و ورود از مرورگر | | |
| ☐ | ارتقا از پنل | بسته‌ی نسخه‌ی بعد را در «بکاپ و ارتقای سیستم» بارگذاری کنید | مراحل و لاگ در صفحه، نسخه‌ی جدید بالا می‌آید | |
| ☐ | ارتقا از CLI | `scripts/upgrade.sh <bundle>` | | |
| ☐ | برگشت خودکار | بسته‌ای که سرویسش بالا نمی‌آید | نسخه‌ی قبل و دیتابیس آن برمی‌گردد | |
| ☐ | بکاپ و بازیابی | عبارت عبور، «بکاپ کامل الان»، روی **سرور دوم** نصب و `scripts/restore.sh` | ورود با همان کاربران، دستگاه‌ها و بکاپ‌ها؛ کلید اصلی برگشته | |
| ☐ ⚠️ | کپی SFTP | سرور SFTP سازمان، «آزمایش اتصال»، بکاپ | فایل روی SFTP، نگهداری تعداد نسخه | |
| ☐ | محدودیت فایل باز در ClickHouse | `ulimit` میزبان ۲۶۲۱۴۴ را مجاز کند، وگرنه `TAKTAPLUS_CH_NOFILE` | | |
